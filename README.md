# 피아노 연습 도우미

디지털 피아노(롤랜드 F107)를 USB 케이블로 태블릿에 연결해, 처음부터 배우고 연습하는 앱.

- 앱 주소: https://htcho-max.github.io/piano-practice/ (main 에 push 하면 GitHub Actions 가 시험 → 빌드 → 배포)
- 입력: Web MIDI (크롬, HTTPS) — 누른 건반·세기·페달. 피아노가 없으면 화면 건반·컴퓨터 키보드
- 기록: 기기 안(IndexedDB)에만 저장

## v0.1
- 피아노 연결 화면, 화면 건반(터치), 누른 음·코드 이름·세기·페달 표시, 메트로놈
- 배우기 1~8과: 건반 지도 → 손가락 번호 → 오른손 첫 곡 → 박자 → 왼손 → 양손 번갈아 → 양손 함께 → 첫 양손 곡
- 연습 방법 두 가지: **기다려 주기**(맞는 건반을 누를 때까지 기다림) / **박자 맞춰**(한 마디 세고, 빠름·늦음·놓침·양손 어긋남 채점)
- 한 손만 연습 (박자 맞춰에서는 다른 손을 앱이 연주), 들어 보기
- 오늘의 연습(손 풀기 · 새로 배우기 · 다시 하기), 연습 시간·연속 일수, 기록

## v0.2
- 큰보표 악보 그리기 (src/music/layout.ts + components/Staff.tsx, Bravura 글꼴 윤곽 src/music/glyphs.ts — SIL OFL 1.1): 높은음·낮은음자리표, 덧줄, 임시표(마디 안 유지·제자리표), 점음표, 8분음표 꼬리, 쉼표 자동 채움, 3/4·4/4
- 음표 읽기 퀴즈 8단계 (도 자리 → 한 옥타브 → 낮은음자리표 → 큰보표 → 솔 자리 → 샵·플랫 → 덧줄): 약한 음이 더 자주, 기록(read-stats)
- 배우기 9~16과: 높은음자리표, 낮은음자리표, 큰보표, 점음표와 3박자(왈츠), 솔 자리(나비야), 샵과 플랫(레 자리), 건너뛰기와 첫 화음, 악보 보고 양손 곡(징글벨)
- 연습 화면: 악보 / 이름 칸 보기, 건반 힌트 끄기 (틀리면 그 칸만 보여 줌)
- 박자 채점 보정(설정, 결과 화면에서 자동 제안)
- 오늘의 연습에 9과부터 '음표 읽기 3분'

## 개발
```
npm install
npm run dev        # 컴퓨터에서
npm run phone      # 같은 와이파이의 태블릿에서 (https 임시 인증서)
npm test           # 단위 시험
npm run smoke      # 빌드 + 가짜 MIDI 피아노로 화면 흐름 시험 (playwright)
```
연습 곡 글 형식(src/music/steps.ts): `R1:C4/q L5:C3+R3:E4/h r/q` — 손·손가락:음/길이(w h q e s, 점은 '.'), 동시에는 '+', 쉼표 r.
