# 피아노 연습 도우미

디지털 피아노(롤랜드 F107)를 USB 케이블로 태블릿에 연결해, 처음부터 배우고 연습하는 앱.

- 앱 주소: https://htcho-max.github.io/piano-practice/ (main 에 push 하면 GitHub Actions 가 시험 → 빌드 → 배포)
- 입력: Web MIDI (크롬, HTTPS) — 누른 건반·세기·페달. 피아노가 없으면 화면 건반·컴퓨터 키보드
- 기록: 기기 안(IndexedDB)에만 저장

## v0.1
- 피아노 연결 화면, 화면 건반(터치), 누른 음·코드 이름·세기·페달 표시, 메트로놈
- 배우기 1~8과: 건반 지도 → 손가락 번호 → 오른손 첫 곡 → 박자 → 왼손 → 양손 번갈아 → 양손 함께 → 첫 양손 곡
- 연습 방법 두 가지: **기다려 주기**(맞는 건반을 누를 때까지 기다림) / **박자 맞춰**(한 마디 세고, 빠름·늦음·놓침·양손 어긋남 채점)
- 한 손만 연습 (박자 맞춰에서는 다른 손을 앱이 연주), 들어 보기
- 오늘의 연습(손 풀기 · 새로 배우기 · 다시 하기), 연습 시간·연속 일수, 기록

## v0.7 — 멜로디 보이싱 양손 반주
- src/music/melodyvoice.ts: 멜로디를 오른손 맨 위에 두고 그 아래 코드 음을 채우는 편곡 (① 멜로디+베이스 ② +한 음(3·6도) ③ 멜로디 맨 위 3음 화음 + 왼손 근음·5음 ④ +왼손 펼친화음). 화음은 코드가 바뀌는 음·마디 첫 박·긴 음(코드 음일 때만), 당김음은 새 코드로, 아래 음은 멜로디 음 길이만큼(이어지는 소리는 페달)
- 곡: "코드로 반주 만들기"에 양손 ①~④ 추가
- 자유 반주 (src/practice/free.ts): 악보는 멜로디+코드만, 멜로디를 맨 위로 치고 아래는 마음대로 코드 음 — 코드 밖 음·멜로디가 맨 위인지·코드가 바뀌는 곳 화음(● 둘 이상 ◐ 하나) 채점 (점수 = 멜로디 60 + 화음 40). 코드가 있는 곡마다 연습 방법에 '자유 반주'
- 보이싱 연습 (VoiceDrill): 코드 + 맨 위 음 → 멜로디가 맨 위인 화음 (어느 자리든 맞으면 통과), 코드 탭 '보이싱' (진행 × 조), 배우기 26·27과
- 화면 건반: 칠 건반이 스크롤 밖이면 자동으로 옮김
- v0.7.1: 아래 음 길이 = 멜로디 길이(악보와 같게), 보이싱 추천 손가락, 자유 반주 약한 마디, 기록 이름(코드·음계·내 곡·자유 반주)

## v0.8 — 읽기 쉬운 악보, 박자 맞춰 자유 반주
- 악보 빔: 한 박(6/8 은 점4분) 안의 8분·16분을 묶음, 16분은 둘째 빔·짧은 빔, 살짝 기운 빔 (layout.ts beams, Staff.tsx)
- 16분 자리에서 박을 넘는 당김음은 박에서 나눠 붙임줄 (♪♩·♪♩. 은 그대로), 코드 이름 겹치지 않게
- 자유 반주 '박자 맞춰' (FreeTimedGrader): 멜로디 박자 + 코드가 바뀌는 곳 화음 + 코드 밖 음 + 코드 바뀔 때 페달. 앞 멜로디 음을 누르고 있는 레가토는 '맨 위 아님'으로 안 봄

## 개발
```
npm install
npm run dev        # 컴퓨터에서
npm run phone      # 같은 와이파이의 태블릿에서 (https 임시 인증서)
npm test           # 단위 시험
npm run smoke      # 빌드 + 가짜 MIDI 피아노로 화면 흐름 시험 (playwright)
```
연습 곡 글 형식(src/music/steps.ts): `R1:C4/q L5:C3+R3:E4/h r/q` — 손·손가락:음/길이(w h q e s, 점은 '.'), 동시에는 '+', 쉼표 r.
